# Prompt per AI generativa di immagini — Dottò

Questo documento contiene prompt pronti per generare immagini che rappresentino la piattaforma **Dottò** (sistema valet biciclette per eventi) sia **lato utente** che **lato operatore**. Usali con Midjourney, DALL·E, Stable Diffusion, Ideogram o simili.

---

## Contesto progetto (da includere mentalmente in ogni prompt)

- **Nome**: Dottò — Sistema Valet Biciclette per Eventi  
- **Brand**: Scintilla Cicloprogetti  
- **Cosa fa**: prenotazione posti bici, check-in/check-out con QR (digitale o gettone fisico), gestione rastrelliere e slot  
- **Stile UI**: interfaccia moderna, pulita, mobile-first; blu come colore primario (#1a7cf1 circa); font system-ui/sans-serif; componenti arrotondati (Mantine-style)  
- **Setting**: eventi all’aperto (concerti, fiere, festival), parcheggio bici con rastrelliere, operatore con tablet/smartphone, utenti con bici  

---

## 1. Lato utente

### 1.1 Landing page prenotazione evento (mobile)

```
Mockup di schermata smartphone: app di prenotazione valet bici per un evento. In alto logo "Dottò" e titolo evento tipo "Concerto al Parco". Sotto: luogo, data, orario. Barra di progresso "94/120 posti" con percentuale. Form con campo Email obbligatorio, campo Telefono opzionale, checkbox Newsletter. Pulsante grande "Prenota ora". Stile UI moderna, blu primario, sfondo chiaro, mobile-first. Testo in italiano. Alta fedeltà, non illustrazione.
```

**Variante (tablet/desktop):**
```
Stessa landing page prenotazione valet bici "Dottò" ma su layout tablet o desktop: card centrale con disponibilità posti, form email/telefono, pulsante Prenota. Colori blu, UI pulita, testo italiano.
```

---

### 1.2 Conferma prenotazione con QR (mobile)

```
Mockup smartphone: schermata "Prenotato!" dopo aver prenotato il posto bici. Grande QR code al centro, sotto codice tipo "DOT-K8M2". Nome evento, luogo, data. Pulsanti "Aggiungi a Wallet" e "Condividi QR". Testo "Mostra questo QR all'ingresso con la tua bici". UI blu e bianca, pulita, mobile. Italiano.
```

---

### 1.3 Utente che mostra il QR all’ingresso (scena reale)

```
Foto realistica: persona in bicicletta davanti a un banco valet bici all'aperto, tiene in mano lo smartphone con uno schermo che mostra un QR code grande. Operatore con tablet in mano sullo sfondo, rastrelliere con bici in parco o piazza. Giornata soleggiata, atmosfera evento (concerto/festival). Nessun testo leggibile sul telefono, solo sensazione di "mostra QR per check-in".
```

---

### 1.4 Flusso utente completo (storyboard in una sola immagine)

```
Composizione orizzontale a 3 pannelli tipo storyboard: (1) persona al PC/telefono che prenota con form email; (2) smartphone con schermata "Prenotato" e QR code; (3) stessa persona in bici che mostra il telefono a un operatore davanti alle rastrelliere. Stile UI coerente blu/bianco, ambiente evento all'aperto. Etichette in italiano: Prenota, Ricevi QR, Check-in.
```

---

## 2. Lato operatore

### 2.1 Login operatore (tablet)

```
Mockup tablet: schermata di login per operatori valet bici. Campo "PIN" (nascosto), logo "Dottò" in alto, pulsante "Accedi". Design minimale, blu primario, sfondo neutro. Mobile-first, orientamento orizzontale. Italiano.
```

---

### 2.2 Dashboard operatore (tablet)

```
Mockup tablet: dashboard operatore valet bici. In alto nome evento e luogo. KPI: "94/120 posti", "26 liberi", anelli o barre di progresso. Pulsante prominente "Check-in". Tabella o lista "Bici parcheggiate" con token, slot, orario. Footer con link Check-in / Check-out. UI blu e bianca, numeri grandi e leggibili, stile dashboard moderna. Italiano.
```

---

### 2.3 Check-in — Scansione QR cliente (tablet/smartphone)

```
Mockup tablet o smartphone: schermata check-in operatore. Titolo "Token digitale", area centrale con rettangolo "Scansiona QR cliente" (come viewfinder camera). Sotto: "Rast. 3, Slot 7 (auto)" e pulsante "Conferma check-in". Header con "Dottò", contatore posti, evento. UI blu, pulita, mobile-first. Italiano.
```

---

### 2.4 Check-in — Token fisico con foto bici (tablet)

```
Mockup tablet: schermata "Token fisico" per cliente senza smartphone. Area "Scansiona gettone fisico", poi sezione "Foto bici obbligatoria" con placeholder immagine/fotocamera. Assegnazione "Rast. 3, Slot 7" e pulsante "Conferma check-in". Avviso "Usa solo se il cliente NON ha smartphone". Stile coerente blu/bianco. Italiano.
```

---

### 2.5 Check-out — Scansione QR per restituzione (tablet)

```
Mockup tablet: schermata "Check-out". Titolo, area "Scansiona QR cliente", sotto pulsante "Conferma restituzione" e link "Prenotazione persa? Cerca bici/posto". Header Dottò e evento. UI moderna blu, mobile-first. Italiano.
```

---

### 2.6 Operatore sul campo con tablet (scena reale)

```
Foto realistica: operatore in maglietta o gilet, in piedi davanti a rastrelliera piena di bici, tiene in mano un tablet che mostra una schermata con lista o dashboard (colori blu, numeri, pulsanti). Sullo sfondo parco o piazza, altro operatore o utente con bici. Giornata di evento, luce naturale. Atmosfera professionale ma informale.
```

---

### 2.7 Mappa rastrelliere (dashboard)

```
Mockup schermata: vista "Mappa rastrelliere" per operatore. Griglia o mappa schematica con più rastrelliere (Rast. 1, 2, 3...), slot colorati: verdi liberi, blu occupati, grigi chiusi. Legenda e numeri "94/120". UI blu/verde/grigio, pulita, tipo dashboard. Italiano.
```

---

## 3. Scene contesto evento (atmosfera)

### 3.1 Area valet vista dall’alto

```
Vista dall'alto di un'area valet bici: diverse rastrelliere allineate, bici parcheggiate, due o tre operatori con tablet, fila di ciclisti in attesa. Parco o piazza, tendone o banco "Dottò", bandiere. Giornata di evento, luce naturale. Realistico, non cartoon.
```

---

### 3.2 Bancone operatore con segnaletica

```
Banco o bancone valet bici all'aperto con cartello o banner "Dottò - Valet Bici", tablet su supporto, operatore che scansiona un QR dal telefono di un cliente. Rastrelliere sullo sfondo, ambiente festival o concerto. Realistico, colori brand blu se possibile.
```

---

## 4. Specifiche tecniche consigliate (per qualsiasi tool)

- **Stile**: UI mockup = alta fedeltà, schermate credibili; scene reali = foto realistica, non illustrazione.
- **Lingua**: tutti i testi nelle schermate in **italiano**.
- **Colori**: blu primario (#1a7cf1 / blu intenso), bianco, grigi per testi secondari; verdi per "liberi/successo".
- **Device**: mobile per utente, tablet (o smartphone) per operatore.
- **Suffix generici** (da aggiungere se il tool lo consente):  
  `clean UI, modern app, no clutter, Italian language, professional mockup`  
  oppure per scene reali:  
  `realistic photo, outdoor event, natural light, professional, no text on devices`.
